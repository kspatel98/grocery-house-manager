# Grocery House Manager v77

## Highlights

- Flyer deal cards open full details when clicked.
- Shopping-list flyer cards open the same deal-detail experience.
- Flyer details show postal-code area and nearest retailer location separately.
- Google Places nearest-store addresses are cached for 30 days.
- Maps fallback is used when an exact address cannot be resolved.
- Static/non-working flyer merchant chips have been replaced by postal-code merchant discovery.
- Filters use discovered merchant IDs when available.
- Up to 12 explicit flyer stores can be selected to preserve provider cost controls.
- Flyer source URLs are supported when a provider returns one.
- New flyer/filter/modal strings are included in English, Gujarati, Hindi, and French localization.

See `V77_CLICKABLE_FLYERS_STORE_LOCATIONS.md` for implementation details.
