# V90 — Dark Contrast + Automatic Trip Check Hotfix

This is a focused visual hotfix on top of V89.

## Changes
- Leaves the accepted V89 light theme unchanged except for **Family Plus • Automatic Trip Check**.
- Rebuilds Automatic Trip Check colors so its status badge, data-source pills, location form, action buttons, result preview, guidance, and store detail cards stay readable in light mode.
- In dark mode, increases separation between the page canvas, primary panels, nested cards, form fields, tables, buttons, badges/chips, and status elements.
- Raises secondary text contrast in dark mode and strengthens borders/focus states.
- Adds explicit dark colors for Automatic Trip Check so later generic theme rules cannot wash it out.
- Keeps semantic warning/error/success states visually distinct.

No API, database, recipe, or business-logic changes are included in this hotfix.
