# GHM V130 — Guided registration onboarding

V130 turns the V128 onboarding content into a real first-run experience instead of an inline section users have to discover.

## Changes
- New/empty accounts automatically get a modal/full-screen onboarding experience when they reach GHM after registration/sign-in.
- Step 1 creates the first Grocery Home inside onboarding; the user no longer has to find the old form lower on the Home page.
- Household type is selected using large readable cards.
- After the home is created, the same onboarding flow continues into the outcome-first personalization questions.
- Activation guidance remains explicit and then hands off to the cross-page Setup Coach for real inventory/shopping actions.
- Existing established households are still not forced through the onboarding flow.
- Setup percentage/minimized setup pill has explicit high-contrast light-mode styling.
- Mobile onboarding becomes a full-height guided screen with one decision area at a time.
