# Grocery House Manager V82 Release Notes

## Expenses dashboard redesigned around monthly life

- Added automatic monthly books from expense dates; users never create a month manually.
- Added current-month snapshot for total house spend, signed-in user's share, amount paid upfront by the signed-in user, and current net balance.
- Added House expenses / My expenses views.
- My expenses use the user's assigned share, not the full amount of bills they paid upfront.
- Added insight ranges for current month, 2, 4, 6, 12, 24 months, and all time.
- Added category and month insight modes for both house and personal spending.
- Added graphical month cards; selecting a month filters expense activity.
- Added month-grouped reimbursement history with personal and whole-house views.
- Reimbursements remain excluded from spending totals because they settle balances rather than create new spending.
- Preserved V80 smart custom splitting, visual categories, receipt-to-expense handoff, and reimbursement actions.
- Preserved V81 direct TheMealDB integration.
