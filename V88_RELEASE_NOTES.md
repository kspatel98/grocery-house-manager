# Grocery House Manager v88

**Professional dark mode, cleaner mobile navigation, stable expenses, compact flyers, provider-cost caching, and photographic meals.**

Highlights:

- Logo always returns to the full public information page.
- Dark mode is available before and after login and persists across sessions.
- Login/registration has a new professional graphical layout.
- Authenticated mobile header is simplified to logo + current section + account.
- Language, premium status and dark mode live in the mobile More sheet.
- Removed the unstable floating Add Expense button and duplicate Activity Add button.
- Added graphical expense Edit/Delete actions.
- Shopping price-check state is orange/animated while checking and green/static when complete.
- Flyer-list deal cards are compact.
- Canadian price comparisons reuse a 24-hour PostgreSQL cache by default.
- Store product lookup uses a 24-hour cache; universal product metadata uses a 30-day cache.
- All 61 built-in recipes have photographic food imagery, with exact-image enrichment when a confident TheMealDB match exists.
- Expanded dark-mode contrast coverage for cards, forms, tables, modals, navigation and public pages.
